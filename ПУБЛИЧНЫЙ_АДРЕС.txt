Автопубликация:
- Push в ветку main автоматически запускает GitHub Actions.
- Workflow собирает сайт с корневым путём и адресом https://pavelpronin.art/.

Что осталось для запуска домена:
- Custom domain `pavelpronin.art` уже указан в Settings → Pages.
- DNS-записи обновлены владельцем домена; нужно дождаться, пока публичные DNS-серверы начнут возвращать адреса GitHub Pages.
- После проверки DNS дождаться выпуска сертификата и включить Enforce HTTPS.
