## 4. Проверки (обязательно, правило `AGENTS.md`)

Сайт mobile-first. После каждой правки вёрстки проверять мобильную и десктопную версии.

### Быстрый способ — готовый скрипт
```powershell
npm install --no-save puppeteer-core
node scripts/check-responsive.mjs
```
Скрипт сам найдёт установленный Chrome, пройдёт по ширинам 320, 360, 390, 768,
1024, 1152, 1280, 1440, 1920, снимет скриншоты в `%TEMP%\opencode\shots\` и напечатает:
высоту шапки, переполнения шапки и документа, размеры кнопок и пунктов мобильного
меню. Это заменяет мучительные вопросы «а не переносится ли шапка».

Можно сузить список ширин: `$env:WIDTHS='1280,390'; node scripts/check-responsive.mjs`.

Подтверждённые значения на момент передачи:
- высота шапки 64px на всех ширинах от 320 до 1920, переноса нет;
- на 1024px шесть кнопок 75–118×40px, на 1280px — 90–139×40px;
- переполнения шапки нет ни на одной ширине;
- мобильное меню: 6 пунктов по 342×44px;
- карточки контактов: 270×172px на 1440 (4 в ряд), 342×145px на 390 (4 в столбец);
- раздел новостей: карточка анонса на главной — 1152×139px (первая, во всю
  ширину) и 564×132px на 1440; на `/news/` — 368×132px в три колонки,
  на 390px — 342×132px в одну; переполнения нет на 320/390/768/1024/1440.

### Подводные камни, на которые уже наступили
1. **PowerShell ломает кавычки** в `node -e "..."`. Если в JS-коде нужны двойные
   кавычки — пишите одноразовый скрипт во временную папку и запускайте через
   `node <файл>`, либо используйте в JS только одинарные кавычки.
2. **PowerShell 5.1 читает UTF-8 как ANSI.** `Get-Content -Raw` / `Select-String` по
   файлам с кириллицей дают мусор, любая регулярка с русским текстом молча не
   срабатывает — выглядит как «правки не применились». Проверять порядок пунктов,
   тексты и разметку с кириллицей надо через Node (`node <файл>.mjs`) или `read`/`grep`.
   На этом уже потеряно время: скрипт проверки показал «42 файла неверны», хотя
   всё было правильно.
3. **Скрипты с `import` из временной папки не находят пакеты проекта.**
   `puppeteer-core` ставится в `node_modules` проекта, и Node ищет его от места
   файла. Одноразовые скрипты, которым нужен puppeteer, кладите в корень проекта
   (`tmp-*.mjs`) и удаляйте после — в git они не попадут.
4. **Headless Chrome на Windows зажимает окно до 504px** (`--window-size=390`
   реально даёт `innerWidth = 504`). Скриншот врёт. Для честной проверки — только
   puppeteer с `page.setViewport()`, как в скрипте выше.
5. **Локальный сервер: `vite preview` не работает** (слушает 4173, но соединение
   отклоняется). Loopback при этом **не** закрыт — на шаге 6 всё проверили без
   деплоя: маленький `tmp-serve.mjs` в корне отдаёт `dist` по адресу
   `http://127.0.0.1:4411/pavel-pronin-site2/`, дальше
   `$env:SITE_URL='http://127.0.0.1:4411/pavel-pronin-site2/'; node scripts/check-responsive.mjs`.
   Важно: в сборке внутренние пути начинаются с `/pavel-pronin-site2/`, поэтому
   сервер должен отдавать `dist` **под этим префиксом**, иначе отдаст 404.
   `file://` не годится — ES-модули блокируются политикой CORS.
6. **После `git push` деплой доезжает не сразу.** Первый замер сразу после пуша
   показал старый порядок пунктов. Ждать 60–90 секунд и перепроверять.
7. **Медиазапрос не добавляет специфичности.** Если базовое правило стоит в CSS
   ниже медиазапроса, медиазапрос молча проиграет каскад и не применится. Так
   уже было с `.hero__title` / `.hero__text`: правила для десктопа стояли выше
   базовых, размеры не менялись, и это выглядело как «CSS не работает». Правила
   для десктопа hero в `layout.css` стоят **после** базовых — так и надо.
8. **Не запускай поиск по `dist/` без ограничения по файлам.** Поиск без фильтра
   по `*.html` выдал 92 совпадения вместе с целыми `<head>` — огромный бесполезный
   расход контекста.
9. `rg` (ripgrep) в этой среде нет. Используй `read`/`grep`/`Select-String`, а для
   массовых обходов по дереву — маленький Node-скрипт.
10. **Блоки, которые появляются при скролле, не видны на скриншоте.** Класс
     называется `.animated` (ставит `IntersectionObserver` в `src/js/scroll-anim.js`),
     а не `.is-visible`. Чтобы снять страницу целиком, сначала прокрути её, потом
     добавь `.animated` всем `.animate-on-scroll`, и только потом `fullPage`-скриншот.
11. **Перевод нельзя применять «на всякий случай».** На шаге 6 RU-страница
     `/news/` показывала английские тексты: карта перевода подставлялась
     всегда, независимо от языка страницы. Сейчас в `src/js/news-feed.js`
     перевод берётся только при `isEn` — `const en = isEn ? newsEn.upcoming : {}`.
     Ровно тот же класс ошибки ждёт в шаге 7 с полями педпроектов.
12. **`generate-news.mjs` проверяется на временной записи.** Пока `posts` пуст,
     генератор молча ничего не делает, и поломка в нём не всплывёт. Перед тем
     как закрывать любой следующий шаг, где генератор завязан на пустой массив,
     впиши тестовую запись, собери, посмотри `dist/.../<slug>/index.html` и
     убери её.
